# รีวิวเว็บคลังความรู้แมวอักษร · 10 พ.ย. 2569

รีวิวจากภาพหน้าจอเว็บจริงทุกหน้า (เดสก์ท็อป 1280px และมือถือ 390px) เช็กการล้นจอบนมือถือ และวัดน้ำหนัก/เวลาโหลด
สถานะ: ✅ ทำแล้วในโค้ด · 👥 ต้องให้ทีมทำ (ข้อมูลจริง ชื่อ เบอร์ รูป การขออนุญาต) · ⚙️ ทำแล้วแต่ต้องเปิดใช้เอง

## ต้องแก้ก่อนนำเสนอ

| # | ปัญหา | ที่ไหน | สถานะ |
|---|---|---|---|
| 1 | หน้าแมวกว้างเกินจอมือถือ (586px บนจอ 390px) เพราะแถวรูปย่อ | หน้าแมวทุกตัวบนมือถือ | ✅ |
| 2 | ชื่อทีมยังเป็น "สมาชิกกลุ่ม 1, 2, 3" | เกี่ยวกับเว็บนี้ | ✅ ซ่อนจนกว่าจะใส่ชื่อจริง · 👥 ใส่ชื่อใน `config.js` `CREDITS_TEAM` |
| 3 | บทความทุกเรื่อง "ยังไม่ได้ตรวจทาน" บทความทั่วไปเขียนที่มาว่า "ตัวอย่าง — รอผู้ดูแลตรวจทาน" และหน้าเกี่ยวกับฯ ขึ้น "สำเนาในเว็บ" สีส้ม ดูเหมือนข้อมูลปลอม | คลังความรู้ บทความ เกี่ยวกับฯ | ✅ เขียนที่มาให้ตรงจริง · 👥 ให้ผู้ดูแล/สัตวแพทย์ตรวจ 2–3 เรื่องแล้วใส่ `reviewed_by` |
| 4 | หน้าแมวป่วยมีช่องทางติดต่อแค่โรงพยาบาลสัตว์ | แมวป่วย | ✅ เพิ่มแผนที่ ปุ่มพิมพ์โปสเตอร์ จัดหน้าใหม่ · 👥 ใส่ LINE/เบอร์ผู้ดูแลที่ยืนยันแล้วใน `EMERGENCY_CONTACTS` |
| 5 | ชื่อบุคคลจริงในหน้าเกี่ยวกับฯ (ชื่อผู้ดูแลจากชีต) โดยยังไม่ได้ขออนุญาต | เกี่ยวกับฯ หน้าแมว | ✅ แสดงเป็นบทบาทแทน เปิดชื่อได้ด้วย `SHOW_KEEPER_NAMES` · 👥 ขออนุญาตก่อนเปิด |

## รายหน้า

### หน้าแรก 3D (`index.html`)
- [x] มี "5 ขั้น" สองชุดในเว็บ (วงจร KM กับขั้นมือใหม่) คนอ่านจะสับสน → เปลี่ยนชื่อขั้นมือใหม่เป็น "5 เรื่องก่อนไปดูแลแมว"
- [x] หนัก 2.2 MB (three.js 589 KB) โหลดเสร็จ ~3 วิ → แสดงภาพนิ่งของฉากเดียวกันทันที แล้วค่อยเฟดเป็น 3D เมื่อพร้อม

### ภาพรวม (`cats.html#/`)
- [x] ยาวเกินบนมือถือ (6,445px ≈ 7.5 จอ) และซ้ำกับหน้าอื่น (การ์ดหัวข้อ คำพูดผู้ดูแล "ความรู้มาจากไหน") → ตัดเหลือ hero + ค้นหา + แถบแมวป่วย + เริ่มจากตรงไหนดี + หัวข้อในคลัง + แมวในคณะ + บันทึกล่าสุด
- [x] ชิป "คนมักถามว่า" 6 อันกิน 4 แถวบนมือถือ → แสดง 3 อันแรก ที่เหลือกด "ดูเพิ่ม"

### แมวทั้งหมด
- [x] ตัวกรอง 4 แถวก่อนเห็นแมวตัวแรก → บนมือถือพับเป็นปุ่ม "ตัวกรอง"
- [x] ชิปที่อยู่ใช้ชื่อเต็มยาว → ใช้ชื่อสั้น (BRK, MCS, เทวาลัย…)
- [x] แมวที่จากไปแล้วปนอยู่ในตารางหลัก → แยกเป็นส่วน "รำลึก" ท้ายหน้า
- [x] รูปเงาแมวตาสีชมพูดูหลอน → ตาขาวแบบมาสคอต
- [ ] 👥 แมวในคณะ 3 ตัวยังไม่มีรูป (กระตั้ว ทาโร่ มีตังค์)

### หาแมว
- [x] เปิดมาเลือก "ไม่แน่ใจ" ไว้แล้วแต่บอกให้ "เลือกอย่างน้อยหนึ่งอย่าง" → ไม่เลือกอะไรไว้ตั้งแต่แรก และแสดงแมวในคณะทั้งหมดเป็นค่าเริ่มต้น

### มือใหม่เริ่มที่นี่
- [x] บอก "แมวในคณะ 12 ตัว" แต่หน้าอื่นบอก "อยู่ในคณะ 8" → เขียนให้ชัดว่า 8 อยู่ประจำ + 4 แวะมา
- [x] ป้าย SECI ภาษาอังกฤษเป็นศัพท์เทคนิคสำหรับมือใหม่ → ย้ายไปไว้ในคำอธิบาย (tooltip) และหน้าเกี่ยวกับฯ
- [x] ช่อง "ทำแล้ว" อยู่ไกลจากข้อความ → ย้ายมาไว้ใต้ลิงก์ของแต่ละขั้น
- [x] ขั้นที่ 5 ไปดูแลจริง ยังเป็นแค่ข้อความ → มีปุ่มขอนัดไปให้อาหารด้วยกัน (Socialization)

### หน้าแมว
- [x] เรื่องสุขภาพเขียนแค่ "ไต" → "เรื่องไต (ตามข้อมูลในชีต)"
- [x] คำบรรยายเป็นข้อความดิบจากชีต → แสดงเป็นคำพูดผู้ดูแล
- [x] "อายุ 10 กว่า" → "อายุ 10 กว่าปี"
- [x] รหัสตึก BRK/MCS ไม่มีชื่อไทย → เติมชื่อตึกครั้งแรกที่เจอ
- [x] แสดงพี่น้อง/แม่ลูกในหน้าแมว (แทนหน้าผังครอบครัว)
- [x] "เห็นล่าสุด" จากบันทึกการพบเห็น
- [x] ปุ่ม "เห็นวันนี้" กดครั้งเดียวส่งเลย ไม่ต้องกรอกฟอร์ม
- [x] ปุ่มแชร์ (LINE / แชร์ของเครื่อง)
- [ ] 👥 กิจวัตรและประวัติการดูแลยังว่างเกือบทุกตัว ควรสัมภาษณ์เติมให้แมว 8 ตัวที่อยู่ประจำ
