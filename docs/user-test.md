# แผนทดสอบกับผู้ใช้จริง: คลังความรู้แมวอักษร

ใช้ตอบคำถามเดียวในรายงานบทที่ 4: **เว็บช่วยให้มือใหม่ดูแลแมวได้เร็วและถูกขึ้นจริงไหม**
ผลที่ได้เป็นหลักฐานว่าความรู้ที่เราเก็บมา "ถูกนำไปใช้" (ขั้นสุดท้ายของวงจร KM) ไม่ใช่แค่ถูกเก็บไว้

## ใครมาทดสอบ

- นิสิตอักษรฯ 3–5 คน ที่ **ยังไม่เคย** ช่วยดูแลแมวในคณะ (คนที่จะมาเป็นผู้ดูแลรุ่นถัดไป)
- ถ้าได้ ขอผู้ดูแลรุ่นปัจจุบัน 1 คนมาเป็นคนตรวจคำตอบว่าถูกไหม
- ไม่ใช้สมาชิกกลุ่มหรือคนที่เคยเห็นเว็บแล้ว

## เตรียมอะไรบ้าง

- มือถือของผู้ทดสอบเอง (เว็บส่วนใหญ่ถูกเปิดบนมือถือ)
- รูปแมวจริง 3 ตัวที่ถ่ายในคณะ (ตัวที่มีในชีต เช่น หนูดำ ตัวส้มหนึ่งตัว ตัวลายหนึ่งตัว) พิมพ์หรือเปิดบนอีกเครื่อง
- นาฬิกาจับเวลา และแบบบันทึกท้ายไฟล์นี้
- ขอความยินยอมก่อนเริ่ม: บอกว่าเราทดสอบเว็บ ไม่ได้ทดสอบคน ไม่บันทึกชื่อจริงในรายงาน

## ขั้นตอน (ประมาณ 15 นาทีต่อคน)

### รอบ A: ไม่ใช้เว็บ (วัดฐาน)

ให้ดูรูปแมวทีละรูป แล้วถาม "รู้ไหมว่าตัวนี้ชื่ออะไร ทำหมันแล้วหรือยัง เข้าหาได้ไหม"
ให้หาคำตอบด้วยวิธีที่ปกติจะใช้ (ถามเพื่อน ค้น IG ค้น Google) ให้เวลาตัวละไม่เกิน 3 นาที

### รอบ B: ใช้เว็บ

ส่งลิงก์ https://pheechan.github.io/aksorn-cat-hub/cats.html ให้เปิดเอง แล้วให้ทำทีละงาน
**อย่าช่วยชี้** ถ้าติดเกิน 2 นาทีให้ข้ามและจดไว้ว่าติดตรงไหน

| # | งาน | ถือว่าสำเร็จเมื่อ |
|---|---|---|
| 1 | เจอแมวในรูปที่ 1–3 ตัวนี้ชื่ออะไร | บอกชื่อถูก (ใช้หน้าหาแมวหรือค้นหาก็ได้) |
| 2 | ตัวนี้ทำหมันแล้วหรือยัง เข้าไปจับได้ไหม | ตอบตรงกับข้อมูลในหน้าแมว |

### คำถามหลังทำเสร็จ (2–3 นาที)

1. งานไหนยากที่สุด ติดตรงไหน
2. มีคำไหนในเว็บที่อ่านแล้วไม่เข้าใจ หรือรู้สึกแปลก
3. ถ้าจะมาช่วยดูแลแมวจริง อยากรู้อะไรอีกที่เว็บยังไม่มี
4. ให้คะแนน 1–5: "ถ้าเป็นมือใหม่ เว็บนี้ช่วยให้มั่นใจขึ้นที่จะเข้าไปดูแลแมว"

## สิ่งที่วัดและเอาไปเขียนในรายงาน

- **เวลาระบุตัวแมว** รอบ A เทียบรอบ B (ค่าเฉลี่ยต่อตัว เป็นวินาที)
- **อัตราสำเร็จ** ของแต่ละงานในรอบ B (ทำได้กี่คนจากทั้งหมด)
- **ตอบถูกไหม** โดยให้ผู้ดูแลรุ่นปัจจุบันตรวจ (ความรู้ในเว็บถูกต้องและใช้ได้จริงหรือเปล่า)
- **จุดที่ติดและคำที่ไม่เข้าใจ** เอาไปแก้เว็บ แล้วเขียนเป็นข้อเสนอแนะในบทสรุป
- **คะแนนความมั่นใจ** (คำถามข้อ 4)
- **คะแนนทายแมว** (`#/quiz`): ให้ผู้ทดสอบทำหนึ่งรอบตอนเริ่มรอบ B และอีกรอบตอนจบ คะแนนทั้งสองรอบเข้าชีตรับเรื่องเอง (ประเภท "ผลทายแมว" บอกว่าเป็นครั้งที่เท่าไรบนเครื่องนั้น) หลังส่งงานแล้ว คะแนนจากคนทั่วไปที่เข้าเว็บก็ยังเก็บต่อได้

ถ้ารอบ B เร็วขึ้นแต่ตอบผิด แปลว่าข้อมูลในชีตต้องแก้ ไม่ใช่หน้าเว็บ ให้แยกสองเรื่องนี้ในรายงาน
